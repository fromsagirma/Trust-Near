# TrustNear — System Requirements Specification (SRS)

## 1. Introduction
TrustNear is a location-based platform designed to help people discover trusted nearby businesses and services.

## 2. Product Scope
* User Mobile Application (Guest & Registered Users)
* Business Owner Web Portal
* Admin Web Dashboard
* Unified Backend API (Node.js/Express & Prisma ORM)
* Shared PostgreSQL Database
